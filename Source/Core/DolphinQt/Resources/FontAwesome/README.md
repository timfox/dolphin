# Font Awesome Free icons

Solid-style SVG icons from [Font Awesome Free](https://fontawesome.com) 6.7.2, used for the
devkit editor UI (toolbar, panels, status bar). They are tinted at runtime by
`DolphinQt/IconSet.cpp`, so the files are kept unmodified.

License: icons CC BY 4.0, fonts SIL OFL 1.1, code MIT. See `LICENSE.txt`.

To add an icon, copy `svgs/solid/<name>.svg` from the `@fortawesome/fontawesome-free@6.7.2`
npm package into this folder and list it in `fontawesome.qrc`.
